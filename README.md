# TinyMind AI Render Server

Backend real para TinyMind Kids.

## Render settings

Build Command:
npm install

Start Command:
npm start

## Required Environment Variables

OPENAI_API_KEY
OPENAI_MODEL
FIREBASE_API_KEY

## Routes

GET /
GET /api/health
POST /api/chat
POST /api/create-script
POST /api/create-scenes
POST /api/render-video
